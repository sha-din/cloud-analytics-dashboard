# Cloud Analytics Dashboard (Excel + Power BI + AWS)

## 📌 Overview
This project showcases a **Business Intelligence (BI) dashboard** that integrates Excel datasets, AWS S3 storage, and Power BI.  
It provides comparative analytics for **AWS, Azure, and GCP** in terms of **cost, performance, and SLA compliance**.  

## ⚙️ Features
- Integration of Excel datasets with AWS S3.  
- ETL and data transformation using Power Query.  
- DAX measures for KPIs and advanced calculations.  
- Interactive dashboards with **KPI cards, trend analysis, and provider comparisons**.  
- Automated refresh for real-time reporting.  

## 🛠️ Tech Stack
- Power BI  
- Excel  
- AWS S3  
- DAX  
- Data Modeling
